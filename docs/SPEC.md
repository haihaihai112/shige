# 拾格 0.1 学习版规格

独立编写的 Windows 本地文件收纳工具。名称、代码、图标、文档和应用身份均独立；不导入其他软件的配置或资产。

## 功能

- C# / WinUI 3，简体中文，跟随系统主题，Mica 不可用时纯色背景。
- 首次只提供新建真实文件夹格子或映射已有文件夹；不自动移动任何桌面文件。
- 多个独立文件格子：图标网格、多选/框选、双击交给系统打开；复制、剪切、粘贴、重命名、回收站删除、新建文件夹、拖入拖出；手动/名称/类型/修改时间排序。
- 格子可移动、缩放、锁定、吸附并保存布局。标题改名不改目录；移除格子不删除文件。
- 托盘、普通 F7、单实例，文件夹监听，显示器变化和恢复时纠正出屏位置。
- 手动整理个人桌面普通文件：快捷方式、文档、图片、音视频、压缩包、其他。排除文件夹、系统隐藏文件和临时下载文件。预览、逐项排除、选择新格子或已有目标、确认移动、进度、取消、部分失败、撤销、异常中断恢复。
- 整理移动禁止覆盖，冲突使用明确新文件名。事务在移动前后落盘；撤销需确认文件内容未改变且原位置为空。跨盘移动复制校验后移除源。
- 设置三页：常规、格子、整理。开机启动默认关；F7 可关闭；图标大小、吸附、默认尺寸和锁定；六类默认目标；配置导出/恢复、本地日志。
- 配置使用本地应用数据目录，真实文件默认位于用户目录下 ShigeFiles。恢复配置不恢复文件事务，不移动文件。损坏配置有最近可用副本。
- 不含网络服务、自动整理、搜索、笔记、待办、天气、媒体、皮肤、插件和应用内更新。

## 安全和验收

文件操作的失败必须可见。不提供永久删除；不支持回收站的目标拒绝应用内删除。测试只使用临时目录，不整理真实桌面。自动化重点验证移动、冲突、取消、撤销冲突、异常恢复和配置持久化。构建和 GUI 启动应有实际证据；未进行的硬件场景人工验证要明确列出。
